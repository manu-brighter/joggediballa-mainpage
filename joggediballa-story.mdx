# Die Joggediballa-Story: Vom Vereins-Chaos zur massgeschneiderten Web-Plattform

Als Entwickler sucht man oft nach Projekten, die nicht nur technisch anspruchsvoll sind, sondern auch einen echten Mehrwert im Alltag bieten. Für mich war dieses Projekt die neue Website für den Verein **Jogge di Balla**. Was als einfache Informationsseite begann, entwickelte sich schnell zu einer umfassenden, massgeschneiderten Fullstack-Plattform, die heute das digitale Herzstück des Vereins bildet.

In diesem Showcase möchte ich euch hinter die Kulissen mitnehmen und zeigen, wie ich die Plattform konzipiert und technisch umgesetzt habe.

## Die Ausgangslage und Vision

Vereine kämpfen oft mit denselben Problemen: Excel-Listen für die Mitgliederverwaltung, statische Websites, die bei jeder kleinen Änderung einen Entwickler erfordern, und isolierte Tools für Events oder Sponsoren. Meine Vision für Jogge di Balla war eine **All-in-One-Lösung**.

Die Anforderungen waren klar:
1. Eine moderne, ansprechende öffentliche Website für Fans und Sponsoren.
2. Ein geschlossener Admin-Bereich zur Verwaltung von Mitgliedern, Events und Finanzen.
3. **Vollständige Dynamik**: Jedes Element der Website sollte von den Vereinsmitgliedern selbst über ein Dashboard anpassbar sein, ohne dass der Code angefasst werden muss.

## Der Tech-Stack: Modern, Typensicher, Schnell

Um diese Vision umzusetzen, habe ich mich für einen modernen, stark typisierten Stack entschieden, der sowohl Entwicklungsgeschwindigkeit als auch langfristige Wartbarkeit garantiert.

| Technologie | Einsatzbereich | Warum diese Wahl? |
| :--- | :--- | :--- |
| **React 19 & Vite** | Frontend-Framework & Build-Tool | Bietet eine reaktive, schnelle UI mit exzellenter Developer Experience. |
| **TypeScript** | Sprache (Fullstack) | End-to-End Typensicherheit verhindert Bugs, bevor sie entstehen. |
| **tRPC** | API-Layer | Ermöglicht nahtlose Kommunikation zwischen Frontend und Backend ohne manuelle Typendefinitionen. |
| **Drizzle ORM & MySQL** | Datenbank & ORM | Drizzle ist leichtgewichtig, extrem schnell und bietet volle TypeScript-Unterstützung für SQL-Queries. |
| **Tailwind CSS & shadcn/ui** | Styling & Komponenten | Ermöglicht schnelles, konsistentes und barrierefreies Design. |

## Das Herzstück: Das Admin-Dashboard

Das grösste Feature der Plattform ist für den normalen Website-Besucher unsichtbar: Das Admin-Dashboard. Hier laufen alle Fäden zusammen.

### Dynamisches Berechtigungssystem

Ein Verein hat verschiedene Rollen – vom Präsidenten über den Kassier bis zum einfachen Mitglied. Anstatt Berechtigungen hart im Code zu verdrahten, habe ich ein **dynamisches Berechtigungssystem** entwickelt. 

Über die "Berechtigungen-Card" im Dashboard können Administratoren granulare Rechte (z.B. `edit_events`, `manage_sponsors`, `edit_shotcounter`) an verschiedene Rollen vergeben. Das Backend prüft diese Rechte bei jedem tRPC-Call über eine massgeschneiderte Middleware (`requirePermission()`), was maximale Sicherheit garantiert.

### Mitglieder- und Anwesenheitsverwaltung

Die Zeiten von unübersichtlichen Excel-Listen sind vorbei. Das System bietet eine vollständige Mitgliederverwaltung. Ein besonderes Highlight ist das **Anwesenheitssystem**:
- Für jeden Event kann eine Anwesenheitsliste generiert werden.
- Die Daten fliessen direkt in eine **Anwesenheitsstatistik**, die grafisch aufbereitet zeigt, wer die aktivsten Mitglieder sind.
- Dies fördert nicht nur die Übersicht, sondern auch ein wenig den internen Wettbewerb.

### Gönnermitgliedschaften und Finanzen

Auch die Verwaltung der Gönnermitglieder (Sponsoren) läuft komplett über die Plattform. Neue Gönner können erfasst, Zahlungen bestätigt und Mitgliedschaften verlängert werden. Das System generiert automatisch den aktuellen Status und zeigt diesen auf der öffentlichen Sponsoren-Seite an.

## Öffentliche Features: Dynamik pur

Die öffentliche Seite ist das Aushängeschild des Vereins. Auch hier lag der Fokus auf Dynamik.

### Events und Fotos

Die Event-Seite ist vollständig dynamisch. Admins können neue Events erstellen, Beschreibungen hinzufügen, Links (z.B. für Tickets oder Anmeldungen) hinterlegen und nach dem Event Fotos hochladen. 

Ein technisches Detail, auf das ich besonders stolz bin: Die **Smart-Thumbnail-Generierung**. Wenn ein Hochkant-Flyer als Event-Bild hochgeladen wird, erkennt das System dies automatisch. Anstatt das Bild unschön abzuschneiden, wird es vollständig angezeigt (`object-fit: contain`), und der Hintergrund wird dynamisch an die dominante Farbe des Flyers angepasst.

### Der Harassenlauf

Für das jährliche Highlight des Vereins, den Harassenlauf, gibt es ein eigenes Modul. Hier können sich Teams online anmelden, und die Daten landen direkt strukturiert im Admin-Dashboard zur weiteren Verarbeitung.

## Das "Schlag den Kassier" Live-Overlay

Ein Feature, das besonders viel Spass gemacht hat, war die Entwicklung eines Live-Overlays für Twitch-Streams. Der Verein veranstaltet ein Format namens "Schlag den Kassier", das live gestreamt wird.

Anstatt auf externe, kostenpflichtige Overlay-Dienste zurückzugreifen, habe ich ein eigenes, massgeschneidertes Overlay direkt in die Plattform integriert.

- **Die Architektur**: Das Overlay läuft unter einer versteckten URL (`/overlay/sdk`), die in OBS als Browser-Source eingebunden wird.
- **Echtzeit-Synchronisation**: Über ein Control-Panel (`/overlay/sdk/control`) kann ein Admin den Spielstand live steuern. Dank tRPC-Polling aktualisiert sich das Overlay im Stream in Echtzeit, ohne dass die Seite neu geladen werden muss.
- **Design**: Das Overlay ist im Vereinsdesign gehalten (Rot/Blau), mit abstrakten SVG-Hintergründen, dynamischen Animationen (z.B. ein goldener Shimmer-Effekt für den Sieger) und einer automatischen Berechnung, wann ein Spieler mathematisch nicht mehr eingeholt werden kann.

## Fazit

Die Entwicklung der Joggediballa-Plattform war eine fantastische Reise. Sie zeigt perfekt, wie moderne Webtechnologien genutzt werden können, um nicht nur schöne Websites zu bauen, sondern echte, massgeschneiderte Softwarelösungen, die den Alltag von Menschen – in diesem Fall eines ganzen Vereins – spürbar erleichtern.

Der Wechsel von statischen Seiten und Excel-Listen zu einer zentralen, dynamischen Fullstack-Applikation hat den Verein digital auf das nächste Level gehoben. Und für mich als Entwickler war es die perfekte Gelegenheit, einen modernen Tech-Stack in einem realen, produktiven Umfeld auszureizen.
